# 주차요금·감면·카드 계산기

[요금 페이지](../web/fees.html)는 2026-10-11 기획 자료와 공식 요금표·상품 안내를 바탕으로 만든 **비공식 참고 계산기**입니다. [계산 규칙](../web/parking-fees.js)과 [화면 코드](../web/fees.js)를 분리했고, 인증키·가맹점 조회·서버 저장 없이 브라우저에서 계산합니다. 차량번호·주민등록번호·카드번호·증빙은 받지 않습니다.

## 기본요금과 차량 구분

| 주차장·규모 | 최초 무료 | 기본/추가 | 일 최대 |
|---|---:|---|---:|
| 단기 소형 | 10분 | 30분 1,200원 / 이후 15분 600원 | 24,000원 |
| 장기 소형 | 10분 | 시간당 1,000원 | 9,000원 |
| 예약 소형 | 10분 | 시간당 1,000원 | 9,000원 |
| 화물 소형 | 45분 | 이후 15분 500원 | 10,000원 |
| 화물 대형 | 45분 | 이후 15분 600원 | 12,000원 |

확인일은 **2026-10-11**이며 시행일은 `null`(미확인)입니다. 과거 입력에 현재 요금표를 적용할 때는 **당시 정책 미확인·재현 가정**을 표시합니다. 주말·공휴일 가산을 임의 추가하지 않습니다.

승용차는 큰 SUV도 요금상 소형입니다. 버스는 15인 이하/16인 이상, 화물은 최대적재량 1톤 이하/초과로 나눕니다. 법정 경차 감면은 요금상 소형과 별개입니다. 단기는 승용차·2.1m 이하로 제한합니다. 장기 대형은 현재 공식 표의 요금이 `-`이므로 **요금 확인 필요**이지 일괄 이용 불가 판정이 아닙니다. 예약 대형은 FAQ 이용 제한을 안내합니다. 예약 높이는 요금표 2.8m·FAQ 3.8m가 충돌하므로 해당 높이 입력에 확인 안내를 제공합니다.

## 시간 계산과 확인 수준

입출차는 기기 시간대와 무관하게 `Asia/Seoul`로 해석합니다. 불가능한 날짜와 역순 입력은 오류이며 동일 시각은 0원입니다. 날짜 개수가 아니라 경과 분과 입차부터 24시간 단위로 계산합니다.

장기 소형의 공개식 검증 범위:

```text
D = floor(경과분 / 1440), R = 경과분 - D×1440
기준 가정 = D×9,000 + min(ceil(R/60)×1,000, 9,000)
R=0이면 잔여 요금은 0원
```

26시간은 11,000원으로 계산하며 남은 하루를 무조건 9,000원으로 올리지 않습니다. 예약은 같은 요율의 참고식을 적용하며, 24시간 기준 자체는 FAQ에서 확인했습니다.

다음은 **정산 규칙이 확정되지 않은 가정**입니다.

- 무료 10분의 포함 경계, 초과 시 무료분 차감/입차부터 계산, 후속 일자 무료 재적용
- 단기 추가 15분의 올림, 후속 일자의 기본 30분 재부과 여부
- 화물 무료 45분 경계와 일자 재적용·15분 올림·24시간 분할

계산기는 단위 올림을 기준 가정으로 보여주고 다른 가정의 금액도 제공합니다. 단기 31분은 단위 올림 1,800원과 구형 공개 함수의 분 비례 1,240원, 24시간 1분은 단위 올림 24,600원과 공개 함수의 24,040원을 구분합니다. 정확히 무료 경계인 시각도 양쪽 가정을 남깁니다. **가정별 금액 범위는 실제 요금의 확정 상·하한이 아닙니다.** 무료시간 분기가 없고 구형 대형 요금이 남은 공식 계산기 전체를 복제하지 않습니다.

최초 무료분 차감 가정도 입차 기준의 24시간 경계를 옮기지 않습니다. 후속 일자에 무료시간을 다시 적용하는 가정은 별도 행으로 구분합니다.

자료 수준은 `공식 확인`(요금표·상품 안내), `계산 검증`(공개식·사례 검증 범위), `조건부 예상`(자격·적용 가정), `추가 확인`(충돌·설명 부족)을 구분합니다. 아직 미확인 경계가 있어 계산기 기본 결과는 조건부 예상입니다.

## 공항 감면과 사후환불

- 경차, 등록 장애인/단체, 해당 등급·등록 유공자, 등록 저공해 1·2종은 50%, 등록 저공해 3종은 20%입니다.
- 다자녀는 2자녀 이상·막내 만18세 이하·한국 국적 가족과 사전등록 승인 조건의 50%입니다. 현장 신청으로 감면을 확정하지 않습니다.
- 여러 자격은 최고율 한 개만 적용합니다. 같은 최고율이면 이미 등록·확인된 자격을 적용 근거로 우선 표시합니다.
- `확인 완료`, `사후 신청 예정`, `등록 모름`을 구분합니다. 전기차 편의 선택은 저공해 등록 확인 상태 없이 자동 확정하지 않습니다.
- 영업 목적은 감면 제외이며 개인 목적 증빙 확인 예외를 제공합니다. 증빙 모름은 감면 미적용/확인 시 결과를 구분합니다.

사후승인 예정 자격은 정산시 감면에 더하지 않습니다. 예를 들어 기본 10,000원에서 저공해 3종 20%를 적용해 **8,000원 정산**한 뒤 50% 자격이 인정되면 **원요금의 차이 30%, 3,000원**을 추가 환불받는 예상입니다. 8,000원의 30%가 아닙니다.

신청은 출차 후 30일(주말·공휴일 포함) 안에 해야 합니다. 계산기에 30일 후의 KST 시각을 참고 기한으로 표시하되 실제 접수 마감과 승인 여부는 공식 사이트에서 확인합니다. 계좌입금/카드 부분취소와 카드 혜택 유지 여부를 별도 입력합니다. 카드 부분취소는 남은 승인액으로 최소결제액을 재판정하며, 유지 미확인은 유지/환수 시나리오입니다. 현금·분할 거래의 환불 배분·취소 후 횟수 복원 등은 추가 확인 항목입니다.

실적은 카드 총사용액이 아니라 카드사 인정 금액을 입력합니다. 숫자를 모르면 구간 충족/미충족/모름을 선택할 수 있습니다. 신규 예외도 기간과 최초 신규 자격을 사용자가 확인해야 하며 갱신·재발급을 자동 신규로 취급하지 않습니다.

Deep Oil의 15만/30만원은 **할인액이 아니라 할인대상 이용금액**입니다. 예: 전월40만원·이번달 정비14만원·주차31,500원이라면 남은 10,000원에 10%를 적용한 **1,000원** 예상입니다. 신규 등록월은 하위 한도이며 이전 달 70만원 인정 실적이 확인된 익월은 상위 한도를 적용합니다. 등록월인지 미확인 상태는 조건부입니다.

삼성의 금액 문턱은 공항 감면 전 기본요금이 아니라 실제 해당 카드 승인액입니다. 다른 삼성 청구할인은 합산하지 않고 큰 혜택 하나를 비교합니다. The CLASSIC AIR와 Deep Oil의 원 미만 할인액 처리도 미확인이라 절사/올림 후보 범위로 표시합니다. 카드 혜택이 없어서 0원인 경우와 조건이 미확인인 경우를 구분합니다.

## 대표 결과와 검증

2026년·장기 소형·감면 승인·삼성 혜택 조건 충족을 가정한 제공 사례:

| 단계 | 금액 |
|---|---:|
| 10/2 07:40 → 10/8 16:33, 6일8시간53분 | |
| 기본요금 6×9,000 + 잔여9,000 | 63,000원 |
| 공항 50% 감면 후·정산 승인액 | 31,500원 |
| 삼성 청구할인 | 10,000원 |
| 최종 부담 | **21,500원** |

The CLASSIC AIR로 각각 전액 결제하는 대안은 6,300원 청구할인·25,200원 부담입니다. 두 카드 할인은 합산하지 않습니다. 전액/실제 승인액을 입력할 수 있고 현금·포인트·분할 카드 결제의 인정 범위는 별도 확인합니다. 포인트 사용 자체를 신규 할인으로 더하지 않습니다.

[단위 테스트](../tests/parking-fees.test.cjs)는 사례, 24/26시간, 무료·단기·화물·자정 경계, 차량분류, 최고 감면율, 사후 차액, 29,999/30,000원, 인정실적·신규 예외·횟수 소진·오프라인/온라인·업종·공유 한도·SFC·부분취소를 검증합니다. 이 테스트는 계산 구현 검증이며 **운영자가 미확인 요금 경계를 확인했다는 뜻은 아닙니다.**
