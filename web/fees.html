주차요금 계산기

한국시간(KST) · 2026-10-11 확인 자료 · 비공식 참고 예상

공항 감면과 카드 청구할인은 별도 단계입니다. 미확인 요금 경계·자격·카드 조건은 확정 정산액으로 표시하지 않습니다.

1. 주차장과 이용시간
시간을 확인해 주세요.

차량 구분 · 기본은 승용차/요금상 소형

요금상 소형과 법정 경차 감면은 다릅니다. 단기는 승용차 전용·2.1m 이하입니다. 장기 대형 요금과 예약 높이 충돌은 별도 확인합니다.

2. 감면·카드 간단 선택(선택)

조건을 모두 입력할 필요는 없습니다. 모르는 감면·카드 조건은 미적용/조건 충족 시의 참고 금액으로 비교합니다.

상세 조건·다중 감면·사후환불
공항 감면 자격 직접 선택

여러 자격 중 최고율 하나만 적용합니다. 다자녀는 사전등록 승인이 필요하고 현장 신청 감면은 불가합니다.

전기차 여부만으로 감면을 확정하지 않습니다. 저공해 등록 조회 · 공식 감면 등록

사후승인은 보장되지 않으며 출차 후 30일(토·일·공휴일 포함) 안에 신청해야 합니다. 공식 사후환불 안내

카드 비교·결제방법

정확한 상품별 조건을 사용합니다. 두 카드를 고르면 각각 결제하는 대안을 비교하며 할인액을 합산하지 않습니다.

다른 카드로 전액 결제하는 대안 비교
검증 사례 입력

제공된 사례의 연도·장기 소형·50% 감면과 삼성 혜택 조건 모두 충족을 가정한 입력입니다. 실제 자격 확인이나 혜택 보장이 아닙니다.

요금표·계산 가정·공식 출처

공식 확인 = 요금표/상품 안내 확인 · 계산 검증 = 공개식/사례 대조 범위 · 조건부 예상 = 자격·범위 가정 · 추가 확인 = 자료 충돌/설명 부족입니다. 확인일은 시행일이 아닙니다.

계산 전 꼭 확인할 사항
  • 현재 요금표를 과거 모든 기간에 확정 적용하지 않습니다. 과거 입력은 현재 요금표 재현 가정입니다.
  • 무료시간 포함 경계·차감·단기/화물 단위 올림과 후속 일자 과금은 미확인입니다. 계산기의 가정별 금액 범위는 실제 요금 상한 보장이 아닙니다.
  • 영업용은 원칙적으로 감면 제외이며 개인 목적 증빙 예외가 있습니다. 차량번호·주민등록번호·카드번호·서류는 받지 않습니다.
  • 예약은 1일 이상 30일 미만, 45일 전~4시간 전 예약 조건을 별도 확인합니다. 보증금·취소/노쇼 비용·발레파킹료는 주차요금과 별개입니다.
  • 예약 높이는 요금표 2.8m·FAQ 3.8m가 충돌하므로 단일 제한값을 확정하지 않습니다.
  • 무료 발레파킹은 주차 공간 이용료 면제가 아닙니다. 포인트는 자산 사용이며 신규 할인으로 더하지 않습니다.
  • THE 1 계열은 전월 30만원 조건(기본 포인트 50만원과 구별)입니다. 감면 병행·특수 결제채널·연간 집계는 카드사 확인이 필요합니다.
  • Deep Oil은 ICN 승인 가맹점의 신한 주차장 업종이 확인돼야 합니다. SFC 후보는 공식 현행 상품설명서 재확인 전 확정 지원하지 않습니다.
  • iD PLUG-IN/AUTO는 케이엠파크만 명시되어 ICN 공식 주차요금에 자동 적용하지 않습니다. 전체 카드시장 목록은 아닙니다.
